# NOVA 별도 비주얼 시안

2026-11-14. 사용자 지정 스킬 design-taste-frontend 적용.
참조: https://www.webdrift.be/en (메인 화면과 본문 확인).
모드: 기존 소개 콘텐츠를 보존하는 별도 시안. 기존 /는 유지, 신규 /concept/ 제공.

## 기존 시안 감사

퍼플 강조색, 밝은 배경, 시스템 한글 산세리프, 8~12px 모서리, 헤더 탐색과 작은 기능 예시를 보유한다.
현재 시안의 구조와 기능은 보존한다. 별도 시안은 정보 구조·NOVA 워드마크를 유지하면서 비주얼을 크게 바꾼다.
메타 제목과 설명은 시안별 구분하며 운영 URL 이전이나 SEO 마이그레이션은 수행하지 않는다. 기존 분석·동의·법적 문구는 추가하거나 변경하지 않는다.

## 디자인 해석

기술 도입 담당자를 위한 브랜드 중심 한 페이지. Webdrift의 어두운 표면·큰 타이포그래피·입체 오브젝트·짧은 모션을 참조한다.
소스·로고·문구·이미지는 복제하지 않는다. NOVA 퍼플을 유지한다.
DESIGN_VARIANCE=8 / MOTION_INTENSITY=6 / VISUAL_DENSITY=3.
기존 HTML/CSS/JavaScript 유지. 네이티브 CSS 미학이며 특정 상용 디자인 시스템을 구현했다고 주장하지 않는다.
헤더는 76px, 제품은 아코디언, 전체 페이지 테마는 한 가지, 라이트 전환 지원.
모션: 제목 진입은 시선 순서, 스크롤 노출은 내용 위계, 아코디언·버튼 전환은 조작 피드백을 위한 것이다. 동작 줄이기 설정에서는 정지한다.

## 자산과 콘텐츠

- site/concept/assets/keycaps.webp: 내장 image_gen으로 만든 UX/CHART/GRID 키캡 콘셉트. 판매 하드웨어가 아니다.
- ux.webp / chart.webp / grid.webp: 기존 로컬 프로토타입 T12/T6/T2의 실제 화면 캡처. 예시 데이터 기반이며 실제 제품 라이브러리 출시를 의미하지 않는다.
- 기능별 상세 데모는 다음 단계라는 상태를 유지한다. 가짜 실적·고객 로고·성능 수치 없음.
- 생성 프롬프트: 프리미엄 CGI 제품 사진, UX 오프화이트·CHART 차콜·GRID 퍼플의 세 키캡 조형, 금속 베이스, 어두운 배경, 실제 재료와 그림자, 다른 문구·로고·UI·빛 번짐 없음.

## 실행

npm.cmd run dev 후 http://127.0.0.1:4000/concept/ 접속.
기존 시안: http://127.0.0.1:4000/.
npm.cmd run build는 두 시안과 필요한 에셋을 함께 dist/에 출력한다. 운영 배포는 하지 않는다.

## 검증

360/390/768/1024/1280/1440px 가로 넘침 없음. 아코디언 단일 열기·키보드, 테마 저장, 모바일 메뉴, 동작 줄이기, 이미지 로딩, 기존 경로 및 비공개 파일 차단 확인. 브라우저 페이지 오류 없음. 초기 Lighthouse 모바일 성능 93·접근성 100·권장사항 100·SEO 100. 이미지 형식을 WebP로 최적화해 히어로 파일을 2,006,021 bytes에서 103,250 bytes로 줄임. 실사용 환경의 성능을 보증하는 수치는 아님.

최종 WebP 빌드 Lighthouse: 성능 91·접근성 100·권장사항 100·SEO 100, LCP 2.3초·CLS 0 (로컬 모바일 시뮬레이션, 측정 환경에 따라 변동). 최종 에셋 경로: site/concept/assets/keycaps.webp. 이미지 생성은 내장 도구, 후처리는 동일 시각의 WebP 인코딩만 수행.
