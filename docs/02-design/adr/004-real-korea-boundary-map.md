# ADR-004: 대한민국 지도 — 실경계 SVG 확정 (저폴리곤/헥스 기각)

- **날짜**: 2026-07-29
- **상태**: accepted (supersedes `../nova-integrated-demo-design.md` §1 결정 C-1/C-2)
- **결정자**: architect

## Context (맥락)

통합 데모의 지도는 GeoAxis 계열 정체성과 직결되고, home.sb도 지도(SIGUNGU.json drillDown)를 대시보드 센터피스로 쓴다(분석 §1-4 탭B). 이전 설계(`../nova-integrated-demo-design.md` §1 결정 C)는 "**저해상 단순화 path**(C-1)" + "**헥스 타일맵 폴백**(C-2, C-1 데이터 생성 막히면 대체 허용)"으로 결정했다. 그러나 이후 사용자가 **저폴리곤 지도를 명시 기각**("이전 저폴리곤은 사용자 지적, 실경계로")했다. 지도가 통합 상황실 탭(T1)과 시각화 탭(T7) 양쪽의 임팩트 위젯이므로 렌더 데이터 방침을 확정해야 한다.

## Decision (결정)

**실경계 대한민국 지도(시도 17 SVG path) 확정.** 저폴리곤·헥스 타일 폴백 **삭제**.

- 공개 라이선스 시도 경계 데이터(southkorea-maps 등) → mapshaper `simplify ~2%`로 단순화하되 **해안선·반도 형상이 "대한민국"으로 즉시 인지되는 해상도** 유지(파일 ≤ 30KB). 저폴리곤(각진 다각형)·헥스(육각 추상화)는 이 인지 요건 미달로 불가.
- 인라인 SVG(외부 지도 라이브러리 CDN 0). T1·T7 공용 렌더러, choropleth 5단 램프(부록 A `--nova-map-1~5`) + 드릴다운(viewBox 확대 + 사업장 마커).
- 색약 대응: 색 단독 금지 — 호버 툴팁 + 범례 + 그리드 표 채널 병행.

## Alternatives Considered (대안과 기각 사유)

| 대안 | 내용 | 기각 사유 |
|---|---|---|
| **저해상 단순화 path(이전 C-1)** | simplify를 과하게(형상 뭉개짐) | 사용자 저폴리곤 지적 대상. "대한민국"으로 인지 약함. **기각** |
| **헥스 타일맵 17(이전 C-2)** | 시도를 육각 타일로 추상 배열 | 사용자 명시 기각. 지리적 인지·드릴다운 서사 불가. **기각(폴백에서도 삭제)** |
| **외부 지도 라이브러리(Leaflet/d3-geo+topojson)** | 정밀 렌더 | 외부 CDN·번들 = 자체완결 원칙 위배. 데모 과중. **기각** |
| **실경계 SVG(simplify ~2%, 채택)** | 형상 인지 가능 해상도 인라인 | 임팩트+자체완결+GeoAxis 정합. **채택** |

## Consequences (결과)

**Positive**
- "대한민국 지도"로 즉각 인지 → 시연 임팩트 확보, home.sb 지도 센터피스 정면 대응 + 상회(실경계·실전환 테마 램프).
- 외부 라이브러리 0(자체완결 유지).

**Negative / Risks**
- 실경계 path 데이터 1회 생성 필요(mapshaper 파이프) — 공개 라이선스 확인 필수(라이선스 표기).
- 폴백 삭제로 데이터 생성이 유일 경로 → 생성 산출물(SVG path)을 자산으로 리포지토리에 보존(재생성 비용 차단).
- 다크/라이트 양 모드에서 램프-배경·인접 시도 stroke 대비 계측 필요(색약 채널 포함).
