# ADR-001: NOVA 통합 데모 = 멀티탭 워크스페이스 (단일 대시보드 압축 반전)

- **날짜**: 2026-07-29
- **상태**: accepted (supersedes `../nova-integrated-demo-design.md` §0 범위 결정)
- **결정자**: architect

## Context (맥락)

NOVA 통합 데모의 벤치마크는 `softbowl.co.kr/SBUxDemo/DashBoard/home.sb`다. 분석(`../../01-plan/nova-integrated-demo-analysis.md`, 소스 실측)의 핵심:

- home.sb 본질(§0-1) = 가상 회사 그룹웨어 셸("SBWS") 안의 **멀티탭 워크스페이스**.
- 통합 장치(§0 판정 2) = GNB **5카테고리 33항목** → 하위메뉴 클릭 → **탭으로 열림**(drag·close 가능, `is-draggable=true`).
- refine 매트릭스(§3)가 우리 산출물에 대해 이미 **"멀티탭 워크스페이스 추가"를 명시 권고**.

그런데 앞선 작업에서 main이 "하나의 대시보드로 압축"이라고 **구조를 즉흥 지시**했고, 그 결과 `nova-integrated-demo.html`은 **한올정밀 단일 대시보드**(뷰 전환 탭 3개 고정)로 만들어졌다. 이는 home.sb 멀티탭 워크스페이스 안의 "메인 대시보드 1탭"에 해당하는 것을 워크스페이스 전체로 오인한 것으로, **33화면 breadth와 멀티탭 UX라는 벤치마크 핵심을 상실**했다(사용자 확인 사고). 구조 결정을 architect가 확정 분석대로 다시 내려야 한다.

## Decision (결정)

**통합 데모 = 그룹웨어 셸(GNB 5카테고리 + 멀티탭 바 + LNB + 페르소나) 안의 멀티탭 워크스페이스**로 확정한다.

- GNB 카테고리의 서브메뉴 항목을 클릭하면 **멀티탭 바에 탭이 추가·전환·닫힘·드래그**된다(home.sb 메커니즘 차용).
- main이 만든 **한올정밀 단일 대시보드(3뷰·14위젯·지도·크로스필터)는 폐기하지 않고 워크스페이스의 플래그십 탭 "T1 통합 상황실"로 통째 편입**한다(그 안의 3뷰는 탭 내부 서브뷰로 강등).
- 즉 이전 산출물은 "틀린 것"이 아니라 "**워크스페이스의 한 조각**"이었다 → 편입으로 자산을 살린다.

## Alternatives Considered (대안과 기각 사유)

| 대안 | 내용 | 기각 사유 |
|---|---|---|
| **A. 단일 대시보드 유지(main 지시)** | 한올정밀 대시보드 1개 + 뷰 전환 탭 3 | ⛔ 벤치마크 핵심(멀티탭·33 breadth) 상실. 분석 §0·§3 권고 정면 위배. spec-integrity 게이트 불통과. **기각** |
| **B. 제품별 데모 링크 허브** | 통합 데모 = 제품 데모들로 가는 링크 모음 | 링크 나열 = home.sb의 "살아있는 업무 시스템" 서사 상실. 셸·페르소나 부재. **기각** |
| **C. 멀티탭 워크스페이스(채택)** | 셸 + 멀티탭 + 33 breadth 복원 + 단일 대시보드 = 편입 탭 | 분석 100% 정합·기존 자산 재사용·breadth 복원. **채택** |

## Consequences (결과)

**Positive**
- 벤치마크 핵심(멀티탭·breadth) 복원 → spec-integrity 게이트 통과 가능.
- 기존 단일 대시보드 자산(크로스필터·실지도·테마·편집) 손실 0 — T1 탭으로 편입.
- "우리 업무도 탭으로 들어온다"는 확장 서사 확보(SI 고객 설득축).

**Negative / Risks**
- 셸 3층 → 5층으로 확장(멀티탭 바 신규) + 탭 매니저(라이프사이클·메모리 관리) 신규 구현 비용.
- 탭 14개 = 파일 크기·구현량 증가 → 범위 현실화(ADR-002)로 통제.
- 상황실 로테이션 타이머의 탭 비활성/닫힘 시 정지 규율 필수(누수 리스크) — 구현 가이드 §7-3.3에 규율 명시.

**Supersedes**: `../nova-integrated-demo-design.md`의 "가상 기업 상황실 1개 시나리오 = 대시보드 3뷰로 압축"(§0 범위 가드). 해당 문서의 위젯 카탈로그·크로스필터·원장·정직 장치 상세는 **유효**(T1 탭에서 그대로 사용).
