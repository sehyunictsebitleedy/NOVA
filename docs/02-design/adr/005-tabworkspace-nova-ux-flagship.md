# ADR-005: 탭 워크스페이스 = NOVA UX 간판 기능 (`TabWorkspace`)

- **날짜**: 2026-07-29
- **상태**: accepted (refines ADR-002 셸 제품 귀속)
- **결정자**: architect

## Context (맥락)

ADR-001로 통합 데모 = 멀티탭 워크스페이스가 확정됐고, 셸은 5층 구조(① 프레임 바 · ② GNB · **③ 멀티탭 바** · ④ LNB · ⑤ 스테이지 · ⑥ 푸터)다. 그런데 기존 설계는 층③(멀티탭 바)을 **"셸 신규 골격"**으로만 서술하고, 셸의 제품 귀속을 ADR-002에서 **NOVA UI**(업무포털 템플릿)로 느슨하게 묶었다.

분석 3차 보강(`../../01-plan/nova-integrated-demo-analysis.md` §1-6, home.sb 소스 실측)이 이 느슨함을 정정한다:

- home.sb 메인 영역 = `<sbux-tabs>` 커스텀 엘리먼트(home.sb L1001-1004).
- `sbux-tabs` = **SBUx(소프트보울 UX 제품) 컴포넌트** — 즉 멀티탭 시스템 자체가 **UX 제품의 간판 기능**이지 셸 배경 골격이 아니다.
- NOVA UX = SBUx 대응 제품([[project_nova_platform]] D4 라인업 1번).
- 분석 §1-6 #10~17은 softbowl이 **안 켰거나 표준에도 없는** 탭 기능(컨텍스트 메뉴·keep-alive·오버플로·핀·세션 지속·배지)을 "NOVA 상회 여지 ⭐"로 명시.

→ 층③의 **제품 귀속을 명확히 하고**, 상회 여지를 **NOVA UX 차별화 기능으로 설계에 박제**할 결정이 필요하다. 이는 ADR-002(GNB 33항목 카테고리 매핑)의 관심사가 아니라 **셸 층의 제품 귀속·간판 기능 정의**라는 별개 관심사다.

## Decision (결정)

**셸 층③(멀티탭 바 + 탭 라이프사이클)을 NOVA UX 제품의 핵심(간판) 기능 `TabWorkspace`로 명시 귀속한다.**

1. **제품 귀속 분리**: 셸 크롬(층① 프레임 바·② GNB·④ LNB·⑥ 푸터) = **NOVA UI**(업무포털 템플릿) 유지. 층③ 멀티탭 바 = **NOVA UX `TabWorkspace`**(간판 기능)로 분리. X-ray 태그 = 층③ `data-nova="ux:TabWorkspace"`, 셸 크롬 `ui:*`.
2. **동등 기능(간판의 하한)**: open/switch/close/drag 재배치/중복 방지/마지막 탭 보호/in-page 렌더 = softbowl `sbux-tabs` 1:1 차용(설계 §3-4 ①표).
3. **차별화 기능(상회) — 분석 §1-6 ⭐ 6종만 채택(발명 0)**: ① 우클릭 컨텍스트 메뉴(닫기 외/전부/오른쪽) ② keep-alive 캐시(전환 시 재렌더 0·상태 보존) ③ 오버플로 스크롤+`▾` 드롭다운 ④ 핀/고정 탭 ⑤ 세션 지속(localStorage 복원) ⑥ 배지·탭별 드롭다운. 구현 스펙 = 설계 §5-6(D1~D6).
4. **데이터 시각화 채움 귀속 동반 명시**: ③ 데이터 시각화 탭군 = **NOVA Chart(ECharts 6.0)** 시연. 차트 타입별 native/custom 커버리지(분석 §2-c) = 설계 §3-5. custom 3종(barrange·areaRange·orgchart 리치노드) 명시.

⛔ 구조(멀티탭·셸 5층·14탭·상황실 편입)는 **불변**. 본 ADR은 **제품 귀속·채움 근거·상회 기능 명시**만 — 임의 구조 확장 아님.

## Alternatives Considered (대안과 기각 사유)

| 대안 | 내용 | 기각 사유 |
|---|---|---|
| **A. 층③ = NOVA UI 셸 골격 유지(기존)** | 멀티탭 바를 셸 배경 크롬으로만, 제품 귀속 느슨 | 분석 §1-6 실측 위배(`sbux-tabs`=UX 제품 컴포넌트). "간판 기능"이 제품 무귀속으로 묻힘 → NOVA UX 세일즈 포인트 상실. **기각** |
| **B. 신제품 "NOVA Tabs"로 분리** | 탭 시스템을 6제품 밖 신규 제품으로 | [[project_nova_platform]] D4 라인업(5제품+Portal) 임의 확장. softbowl도 `sbux-tabs`를 UX 제품 안에 둠. **기각** |
| **C. ADR-002 개정으로 흡수** | 새 ADR 없이 ADR-002에 귀속 추가 | ADR-002 = GNB 33항목 카테고리 택소노미(별개 관심사). Nygard "1결정=1파일" 위배·accepted 결정에 이질 관심사 혼입. **기각**(대신 refine 관계로 링크) |
| **D. 상회 기능 임의 확대**(탭 분리 플로팅 윈도우 등) | 분석에 없는 기능까지 추가 | 분석 §1-6 #15(EXT_WINPOPUP)은 [미확인]·⭐ 미부여. 발명 금지 원칙 위배. **기각**(#15는 로드맵으로만) |
| **E. 층③ = NOVA UX TabWorkspace 명시 + §1-6 ⭐ 6종 실장(채택)** | 제품 귀속 분리 + 상회 여지만 채택 | 분석 100% 정합·구조 불변·발명 0. **채택** |

## Consequences (결과)

**Positive**
- 멀티탭 바가 "배경 골격"에서 **NOVA UX 제품의 팔 수 있는 간판 기능**으로 승격 → 세일즈/데모 서사 강화("이 탭 매니저 = NOVA UX TabWorkspace").
- 상회 6종이 분석 근거(§1-6 ⭐)에 1:1 매여 spec-integrity 재검증 통과 가능(발명 0).
- 셸 크롬(NOVA UI)과 탭 시스템(NOVA UX)의 제품 경계가 X-ray로 시각 증명 → 제품 데모 정체성 선명.
- Chart 채움(§3-5)까지 동반 귀속 → 데이터 시각화 탭군의 제품 근거 확보.

**Negative / Risks**
- 차별화 6종(컨텍스트 메뉴·핀·세션 지속·오버플로 드롭다운·배지) 신규 구현량 증가 → 설계 §5-6에 스펙 고정, §7-3 규칙으로 통제.
- 세션 지속(localStorage) 손상 시 폴백 금지 원칙상 홈 초기화 처리 필요(설계 §5-6 D5 명시).
- 데모 HTML은 외부 CDN 0 원칙상 실 ECharts 미임베드 → 인라인 SVG 드로어 + X-ray로 "정식판=ECharts 6.0" 표기(설계 §3-5). 픽셀 동등성은 레이어2 제품 데모에서 검증(분석 §4 리스크 #10).

**Refines**: ADR-002의 "NOVA UI = 셸(GNB/LNB) 자체" 귀속 서술 중 **층③(멀티탭 바) 부분을 NOVA UX `TabWorkspace`로 정밀화**한다. ADR-002의 카테고리 매핑(33항목→5카테고리)·범위 현실화(채움 14탭)는 **전부 유효**(supersede 아님·부분 refine).
