### 2-2. 셸 레이아웃 — 3층 구조 (데모 크롬 / 회사 셸 / 본문)

**핵심 설계**: 시연 장치·정직 장치는 **데모 프레임 바(NOVA 크롬)**에, 페르소나는 **회사 셸**에 분리 수용한다. 허구(회사)와 사실(데모 컨트롤·예시 배지)이 한 층에 섞이지 않는다 — 배지 수프 없이 정직을 유지하는 구조적 장치.

```
┌ ① 데모 프레임 바 40px (--nova-bg-gnb · NOVA 크롬) ──────────────────────────┐
│ ◆ SEbit NOVA 통합 데모  [예시 데이터]      [▷ 시연] [투어] [X-ray] [편집] [</>] [테마] │
├ ② 회사 GNB 56px (--nova-bg-card + 하단 border) ────────────────────────────┤
│ ⬡ 한올정밀 · 통합 운영 상황실   |경영 현황|전국 사업장|공정 품질|   🔔3  (서) 김서연 팀장 │
├ ③ LNB 232px ──┬ ④ 위젯 그리드 (--nova-bg-page · 12col · gap 16 · pad 20) ──┤
│ 프로필 블록     │  (뷰별 구성 §3)                                            │
│ 메뉴 트리      │                                                            │
│ 바로가기       │                                                            │
├ ⑤ 푸터 32px ──┴───────────────────────────────────────────────────────────┤
│ 본 데모의 회사·수치는 모두 예시입니다 · 한올정밀은 가상 기업 · SEbit NOVA v0.9    │
└────────────────────────────────────────────────────────────────────────────┘
```

| 층 | 스펙 |
|---|---|
| ① 데모 프레임 바 | 좌: 4점 성좌 마크 + 워드마크(오로라 클립 — 화면 내 그라디언트 1/2) + `예시 데이터` sample 배지(**버튼 겸용** — 클릭 시 데이터 소스 패널 §8-2 열림, 전역 유일 배지). 우: 컨트롤 6(시연·투어·X-ray·편집·조립 코드·테마) — ghost 버튼, 활성 시 primary tint + `aria-pressed`. 768px 미만 = [⋯] 오버플로 메뉴로 접힘 |

| ③ LNB | `--nova-bg-card` + 우측 border. 구성: **프로필 블록**(아바타 40px + "김서연 팀장 · 생산운영팀" + 시각 기반 인사말 T5 muted) → **메뉴 트리 2뎁스**(뷰 3 > 소속 위젯 — 클릭 = 뷰 전환 + 위젯 스크롤 + 틸 플래시 600ms. **전 항목 실동작**, G14) → **바로가기**(결재 대기 2 · 새 공지 2 — 카운트는 데이터 원장에서 계수, 클릭 = 해당 위젯 이동). 1024px 미만 = 접힘(햄버거로 오버레이) |

### 4-3. 인사이트 행 (전 위젯 공통 마이크로 패턴)


- T5, `--nova-text-sub`. 선두 글리프 = 4px 다이아(`--nova-primary`). 강조 값 = `<b>` + 시맨틱 컬러(good/warn/critical fg — 방향성 있을 때만, 남용 금지 화면당 강조색 위젯 ≤ 5).

### 9-3. 구현 규칙

1. **토큰 강제**: 토큰 블록 외 HEX 0건(grep 검사). 조건부서식 ▲적/▼청 = `--nova-critical-fg`/`--nova-info-fg`(적/청 관례 — home.sb 동일 문법, 색상만 토큰).
2. **원장 단일 소스**: 위젯 렌더러는 인자로 파생 결과만 받는다. `derive()` 하나가 원장→{kpi, choropleth, top5, insights…} 전부 계산 — 크로스필터·편집 후 `derive()` 재호출 + 영향 위젯만 재렌더(전체 재렌더 금지).
3. **인사이트 파생기**: `insight(위젯id, 파생결과) → {text, tone}` 순수 함수. 문장 템플릿 + 계산값 삽입. ⛔ 정적 문장 상수 금지(G12).
4. **크로스필터 디스패처**: `select(type, value)` 단일 진입(type: div/sido/equip). 상태는 뷰당 1개, 재선택=해제, Esc=전체 해제. 갱신 위젯 목록은 §5-2 표를 상수 매핑으로.
5. **로테이션 엔진**: `setTimeout` 체인(시연 모드에서만 타이머 존재 — 상시 `setInterval` 0 원칙 유지). 상태 {running, view, phase}. 스크립트 액션 = 실제 `select()` 호출(별도 연출 코드 경로 금지 — 시연과 실조작이 같은 코드). 진행 게이지 = CSS transition width(linear 7s), 일시정지 시 `getComputedStyle` 폭 고정. 문서 `pointerdown`/`keydown` 캡처로 자동 일시정지. `matchMedia('(prefers-reduced-motion: reduce)')` 시 엔진 비활성.
6. **지도**: §9-4. 상태 {level: 'nation'|'sido', sido}. 드릴다운 = `viewBox` 전환(400ms `--nova-ease`, reduced-motion 즉시) + 마커 렌더.
7. **편집 모드**: HTML5 DnD(`dragstart/over/drop`) + placeholder. 순서 배열만 저장(`nova-int-layout-v1`: {view: [ids], hidden: [ids]}). 파싱 실패 시 기본 배치 폴백.
8. **메모**: FEED.memos + localStorage `nova-int-memos-v1` 병합. XSS — 저장·표시 시 escape 필수.
9. **투어 엔진**: steps 배열 {target, text, detect(이벤트명)}. detect = 크로스필터 디스패처의 커스텀 이벤트 구독.
10. **접근성 공통**: 어제안 §8 승계(모달 포커스 트랩·복사 aria-live·grid roving tabindex). 추가 — 뷰 탭 `role="tablist"` ←→ 이동 · 지도 시도 path = `role="button"`+`aria-label("경기 · 가동률 91%")`+Tab 순회 가능(`tabindex="0"`) · 시연 버튼은 문서 탭 순서 선두권(G13-①).
11. **반응형 4단**: ≥1280 기본 / 1024(LNB 접힘→햄버거) / 768(위젯 전부 12col 스택·지도 세로비 유지·마스터-디테일 상하 분할·프레임 바 [⋯]) / 375(뷰 탭 가로 스크롤·위젯 패딩 16px). 터치 타깃 ≥ 44px. 가로 스크롤 0(그리드 내부 제외).
12. **금지**: 외부 폰트/아이콘/지도 라이브러리 CDN · 프레임워크. 아이콘 = 어제 인라인 SVG 세트 재사용 + 신규(벨·핸들·eye-off·재생/일시정지·지도핀) 최대 6종.

### 9-4. 지도 SVG 데이터 (결정 C-1)

- **1회 생성**: 공개 라이선스 시도 경계(southkorea-maps 등 공개 데이터) → mapshaper 단순화(simplify ~3%) → SVG path 17개 export → 인라인. 목표 ≤ 15KB. 생성 불가 시 헥스 타일 17 폴백(C-2).
- choropleth 5단 램프 = 부록 A `--nova-map-1~5`(가동률 구간 70/80/85/90/95). 값 없는 시도(사업장 무) = `--nova-bg-surface` + 툴팁 "사업장 없음".
- 호버 = stroke `--nova-border-strong`→`--nova-text-sub` + 툴팁(시도·가동률·사업장 수). 선택 = stroke 2px `--nova-live-base`.
- 색약 대응: 색만으로 값 전달 금지 — 호버 툴팁 + 범례(5단 스와치+구간 수치) + W9 그리드가 동일 데이터의 표 채널.
- 다크/라이트 양 모드에서 램프-배경 경계 대비 확인(인접 시도 구분 = stroke 1px `--nova-map-stroke` 상시).
