# NOVA 브랜드·제품 사이트 기획

> **2026-11-14 사용자 방향 변경**: NOVA 소개 사이트를 먼저 제작하고 UX·Chart·Grid 기능별 데모 사이트를 다음 단계로 만든다. 기존 ②→①→③→④ 순서는 이번 사용자 지시로 대체한다. 현재 소개는 `site/`의 간결한 세로형 한 페이지다. 기존 통합 업무 포털은 예시 프로토타입으로 보존하며 17탭 완성·제품 구현과 구분한다.

작성: 2026-11-10. 사용자 요청: 소프트보울 메인 사이트를 기존 NOVA 기획과 대조해 우리만의 NOVA 사이트 제작.
상태: 로컬 제작 기준안. 장기 제품 아키텍처 변경이나 운영 배포 완료를 의미하지 않는다.

## 1. 목적과 대상

NOVA가 무엇인지 이해하고, 제품을 살펴보고, 업무 포털 데모로 체험하게 한다.
대상은 고객사 기술 도입 담당자·SI 실무자·개발자다.
핵심 메시지: **업무 화면의 기준을 하나로.**
보조 설명: 컴포넌트부터 그리드, 차트, 대시보드까지. NOVA로 연결되는 업무 경험.

## 2. 소프트보울 참조와 NOVA 적용

참조 URL: https://www.softbowl.co.kr/front/main.do (2026-11-10 웹 본문 확인).
현재 확인한 범위는 메인 페이지의 콘텐츠와 링크 구조다. 시각 효과·모바일 동작·하위 데모 전체는 재검증하지 않았다.

| 참조에서 확인한 요소 | NOVA 적용 | 적용 범위 |
|---|---|---|
| 회사소개·솔루션·문의·고객센터 메뉴 | NOVA 소개·제품·통합 데모·개발 가이드 | 제품 브랜드 중심 IA |
| 메인 메시지와 대시보드 진입 | NOVA 가치 제안과 업무 포털 체험 | 자체 문구·자체 화면 |
| Grid·UX·Chart·문서 제품별 소개 | 핵심 5제품과 확장 Doc 소개 | 현재 제공과 계획 구분 |
| 제품 PDF·별도 SITE 링크 | 제품 상세와 실제 체험 연결 | 없는 PDF·목적지 링크 생성 금지 |
| 회사 문화·인증·고객사 | NOVA 구성 원칙과 활용 시나리오 | 실적·인증·고객 로고 임의 사용 금지 |
| 문의 진입 | 확인된 회사 문의 채널 연결 | 연락처 확인 전 가짜 폼·가짜 전송 금지 |

레이아웃·문구·이미지·로고는 복제하지 않는다. 기존 벤치마크 문서의 기능·성능 비교를 이번 웹 확인으로 재검증했다고 주장하지 않는다.

## 3. 전체 구조

① 브랜드·제품 소개 → ② 통합 업무 포털 체험 → ③ 제품별 상세 데모 → ④ 실제 제품·개발자 Portal.
이 네 역할은 유지한다. 이번 소개 사이트는 ①의 로컬 시안이며 회사 전체 사이트나 실제 Portal을 대신하지 않는다.
현재 사용자 저장소에서 소개 시안을 제작한다. 과거 Micro 편입안·배포 도메인은 실제 배포 단계에서 재정합한다.
기존 장기 순서 ②→①→③→④와 통합 데모 17탭 공개 게이트를 유지하되, 이번 요청에 따라 ①의 기획·로컬 제작은 먼저 진행할 수 있다. 이는 11탭 공개 승인이 아니다.

## 4. 메뉴와 페이지 범위

| 메뉴 | 1차 동작 | 이후 확장 |
|---|---|---|
| NOVA 소개 | 메인 가치·구조 섹션 이동 | 별도 브랜드 페이지 |
| 제품 | 제품 목록 및 제품 상세 선택 | 제품별 독립 데모 |
| 통합 데모 | 로컬에서 기존 데모 열기, 예시·11탭 상태 표시 | 17탭 검증 완료 후 공개 URL |
| 개발 가이드 | 제품 구조·상속/복사 설명 | 실제 Portal로 연결 |

1차 화면: 소개 메인, 제품 상세 탐색, 기존 통합 데모 진입. 문의 전송·회원가입·결제·실제 LLM 호출은 범위 밖.
모바일에서 메뉴 열기·닫기 및 항목 선택 후 닫기, 키보드 포커스 복귀를 지원한다.

## 5. 메인 섹션

1. 헤더: SEbit NOVA 워드마크, 제품·데모·가이드 탐색, 체험 진입.
2. 히어로: 핵심 메시지와 실제 NOVA 업무 화면을 활용한 제품 비주얼. 주 CTA는 통합 데모, 보조 CTA는 제품 살펴보기.
3. 플랫폼 개요: UX/UI/Grid/Chart/Dashboard가 하나의 업무 화면을 구성하는 관계.
4. 제품 탐색: 제품을 선택하면 설명·예시·적용 범위·실제 체험 가능 여부가 바뀐다. 동등한 카드 여섯 개로 나열하지 않는다.
5. 업무 시나리오: 운영 상황실·데이터 관리·급여관리·시각화. 현재 있는 화면으로 연결한다.
6. 개발 방식: UX는 상속, UI 템플릿은 복사, 실데이터 연동은 제품 단계 계획이라는 구분.
7. 마무리: 체험과 가이드 진입, 회사 링크, 저작권. 확인되지 않은 실적이나 인증은 제외.

CTA는 동일 목적에 동일 명칭을 사용한다. 미구현 제품별 데모는 설명으로 대체하고 준비중 alert나 빈 창을 열지 않는다.

## 6. 제품별 콘텐츠

| 제품 | 소개 메시지 | 현재 연결 자산 |
|---|---|---|
| NOVA UX | 업무 인터랙션의 공통 기준 | TabWorkspace·T12 |
| NOVA UI | 조합하고 확장하는 업무 화면 | T14 템플릿 예시 |
| NOVA Grid | 조회와 편집을 한 흐름으로 | T2·T3, 대용량·Excel은 계획 |
| NOVA Chart | 데이터에서 판단으로 | T6·T7·T15~17 SVG 데모 |
| NOVA Dashboard | 업무 맥락을 연결하는 상황실 | T1 예시 데이터·위젯 편집 |
| NOVA Doc | 데이터 기반 문서 생성 확장 계획 | 소개만, 생성·다운로드 없음 |

TabWorkspace는 UX 제품 기능, GNB/LNB 등 셸은 UI 템플릿이다.
Nexus·API-On은 연동 기반으로 소개하되 현재 데모가 인증·AI·실데이터를 제공한다고 표현하지 않는다.

## 7. 시각·구현 방향

디자인 해석: 기술 도입 담당자를 위한 제품 중심 B2B 소개 사이트. 정돈된 타이포그래피와 실제 업무 화면이 중심이다.
DESIGN_VARIANCE=5, MOTION_INTENSITY=3, VISUAL_DENSITY=4.
기존 NOVA 딥퍼플을 절제된 단일 강조색으로 유지하고 밝은 중립 배경·짙은 텍스트를 기본으로 한다. 실제 화면 외에 장식용 우주·AI 이미지는 요구하지 않는다.
큰 좌측 정렬 메시지, 우측 제품 화면, 구분선과 여백으로 제품을 설명한다. 라이트/다크 변형을 지원한다.
소개 레이어는 기존 기획의 정적 HTML/CSS/JavaScript로 제작 가능하다. 제품 Nuxt 스택과 혼동하지 않는다.
HTML 데모는 원본 한 개만 유지하고 링크한다. 소개 제작을 이유로 데모를 React/Nuxt로 재작성하지 않는다.

## 8. 수용 기준과 단계

- 문서의 현재 상태와 화면의 제공 기능 설명이 일치한다.
- 모든 CTA에 실제 목적지가 있고 예시·미구현·계획 상태를 구분한다.
- 제품 선택·모바일 메뉴·테마·데모 진입이 마우스와 키보드로 동작한다.
- 360/768/1280/1440px에서 가로 넘침·잘린 글자·탐색 충돌이 없다.
- 링크/버튼/폼을 올바르게 구분하고 포커스·명도 대비·동작 줄이기를 지원한다.
- 문서·Git 메타데이터·자격증명은 향후 공개 사이트 배포물에 포함하지 않는다.
- 성능 수치·실적·고객·인증을 근거 없이 표시하지 않는다.

단계 A: 현재 문서 정합과 사이트 기획(이번 변경).
단계 B: 소개 사이트 로컬 구현·검증.
단계 C: 통합 데모 미구현 6탭과 제품별 데모 확장.
단계 D: 운영 도메인·문의 채널·배포 구조 확인 후 배포. Portal 도메인과 통합 데모 도메인을 혼용하지 않는다.

미확정: 회사 문의 채널, 최종 공개 주소, Micro 편입 방식, T5 최대 행수·T8 세부 범위. 소개 시안 제작의 선행 차단 항목은 아니다.
